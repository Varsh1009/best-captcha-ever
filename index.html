    Every frame is uniform static. The target is only the region where dots move together, so it exists across frames, never in one. Motion-coded CAPTCHAs held up against GPT and Gemini in recent work (IllusionCAPTCHA, WWW 2025 uses illusions for the same human-easy, AI-hard gap).

    The patch wanders and turns every second. Screenshot-act agents take seconds per step. On interactive, multi-step CAPTCHAs the best agent solved 40% vs 93% for people (Open CaptchaWorld, NeurIPS 2025).

    Too perfect = bot

    People trail a moving target by roughly 100–300 ms and wobble. A script that reads the page state tracks with near-zero lag and a glassy path, so the reaction-lag check flags it even if it finds the target.
